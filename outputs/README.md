# Generated Outputs

- `assembler/`: assembler tarafından üretilen `.o` object dosyaları
- `linker/`: linker tarafından üretilen `.linked.json` ve bölgesel `.hex` dosyaları
- `loader/`: UART loader'a gönderilen `.picoimg` dosyaları
- `fpga/`: Gowin build sonucunda dışarı aktarılan son `.fs` bitstream dosyası

Bu klasörlerdeki dosyalar kaynak değildir ve gerektiğinde yeniden üretilebilir.
